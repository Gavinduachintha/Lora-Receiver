# LoRa Tracker (LoRa Receiver)

A KiCad hardware design project for a Raspberry Pi Pico-based LoRa receiver/tracker board. The repository currently contains the core schematic and PCB layout needed to review and continue hardware development.

## Overview

This project appears to target a compact LoRa-focused carrier/interface board around a **Raspberry Pi Pico** module, with dedicated connectors for:

- a LoRa interface (left/right header split),
- a display connector,
- battery input,
- and a board-level power switch.

> **Status note:** behavior such as actual RF performance, firmware feature set, tracking accuracy, and field reliability is **not verifiable from this repository alone** and should be treated as implementation goals until validated in hardware and firmware testing.

## Design goals (intended use)

Based on the KiCad project naming and net labels, intended goals likely include:

- hosting a Raspberry Pi Pico as the control MCU,
- exposing LoRa and display-related signals via pin headers,
- providing external power input and a simple power control path,
- serving as a base for a LoRa receiver/tracker build.

These goals are inferred from the current schematic/PCB content and should be validated against firmware and system-level requirements.

### Important filename note

This repository intentionally uses filenames with spaces (for example, `LoRa Tracker.kicad_pro`). Keep names and paths intact unless you plan a coordinated rename across all project references.

## Recommended review/manufacturing workflow

Use the following as a **recommended** workflow (not proof of completed fabrication):

1. Inspect schematic connectivity and component intent.
2. Run **ERC** in schematic editor and review warnings/errors.
3. Open PCB and run **DRC**.
4. Verify footprints, connector orientation, and board outline on `Edge.Cuts`.
5. Generate fabrication outputs (Gerbers, drill files, BOM/position data as needed).
6. Assemble prototype hardware.
7. Bring up firmware and perform electrical + functional tests.
